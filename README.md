# office-jokes

A one-line office joke for the "Make the AI Judge Laugh: Office Jokes" bounty on make.fun. The program writes a single joke about office life (under 200 characters) to `/output/entry.txt`, where the judge compares it head to head with the other entries.

## Run it

```sh
python3 main.py
```

That writes the joke to `/output/entry.txt`.
